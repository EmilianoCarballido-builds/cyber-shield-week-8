# SME Shield MX
Working slice educativo de Emiliano Carballido, Business Bending Week 8 (MONEY). Español, continuidad, precio mensual y recuperación para pymes mexicanas de 5-25 personas.

**Demo, no servicio de seguridad activo.** No conecta cuentas, verifica respaldos, cobra ni ejecuta cambios. Nunca pide credenciales. Datos del formulario solo en memoria. Guía simulada por defecto; LLM local opcional.

## Diseño antes de código
Ver [docs/PACKET.md](docs/PACKET.md), mockup generado y fuentes. El primer commit de documentación precede al código; el historial preserva la secuencia.

## Ejecución prevista
Node 22+, `pnpm install`, `pnpm dev`, `pnpm test`, `pnpm build`. Instrucciones finales y evidencia se añadirán tras la verificación.
